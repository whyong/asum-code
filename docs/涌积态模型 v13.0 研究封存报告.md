## 一、研究背景与核心问题

本系列研究基于"涌积态宇宙模型"（Accumulated-State Universe Model，ASUM）的 v12.0 框架展开。v12 是一个**封闭系统**（严格守恒质量），通过 Fokker-Planck 方程驱动的相变引擎模拟信息涌现。

v13 系列的核心任务是将 ASUM 从"孤立宇宙"范式重构为**开放耗散地球生态圈**，具体解决以下物理问题：

1. **开放性**：地球是太阳系驱动下的耗散结构，而非封闭系统
2. **生态语义**：将量子/信息域变量重映射为生态/地质域变量
3. **热力学完备性**：同时建模能量输入（太阳泵+地热）与输出（废热辐射）
4. **历史记忆**：化石地层（M*场）如何引导灾后生态复苏

## 五、核心科学发现

### 发现1：废热辐射差异是进化方向的热力学驱动力

```
σ_P(0.006) >> σ_C1(0.002) >> σ_C2(0.0004)
```
有序程度越高的生态态，废热辐射越慢，意味着能量保留效率越高。这创造了一种**热力学棘轮机制**：自然选择偏向 C2 不仅因为 C2"更适应"，更因为 C2 是热力学上最节能的态。这与 Schrödinger 在《生命是什么》中的论断（生命以负熵为食）形成数学具体化。

### 发现2：地热"诺亚方舟效应"验证

EXTINCTION 实验中，核冬天（P_in 压制90%，持续200帧）期间：
- 地热 geo→C1 = 约 1.0 单位/帧（恒定）
- C1 通过化能合成维持底线，**不归零**
- 灾变后 M* 记忆梯度 + C1 种子 → C2 快速重建至46.3%

这与真实白垩纪末期小行星撞击后，深海热液喷口生态系统的存活机制高度类比。

### 发现3：强吸引子的存在性——路径无关终态

EXTINCTION（从霸主起点）与 ABIOGENESIS（从原始汤起点）最终收敛到几乎相同稳态：

```
f_C1 差异：|0.309 - 0.309| = 0.000（完全相同）
f_C2 差异：|0.463 - 0.464| = 0.001（误差级别）
```

这证明系统存在**强吸引子盆地**——TURING_GROWTH 稳态（f_C2≈0.46-0.52）是热力学必然。初始条件只影响到达路径（灾变次数、M*积累深度），不影响最终态的性质。

### 发现4：M* 地层记忆的"抗侵蚀性"

灾变次数与 M* 峰值的负相关关系：

| 灾变次数 | M* 峰值 | 实验 |
|---|---|---|
| 1 | 43.64 | FREE |
| 1 | 36.42 | ABIOGENESIS |
| 2 | 31.93 | EXTINCTION |

**每次灾变约侵蚀 M* 积累的 5-10 单位**，证明化石地层是历史记忆的脆弱载体——大规模灾变不仅消灭生命，还在一定程度上"遗忘"进化历史（类比：陨石撞击掩盖化石层）。

### 发现5：Turing 斑块从 v13.2 开始稳定涌现

在 v13.1 及以前，系统在 UNIFORM_GROWTH 中停滞（C2 空间均质化，无斑块结构）。v13.2 引入废热辐射后，Theta_barrier 可降低至 0.18，触发 C1→C2 的空间分化跃迁，首次形成类似真实地球"热带雨林/草原/沙漠"分布的 Turing 生物群落斑块。
